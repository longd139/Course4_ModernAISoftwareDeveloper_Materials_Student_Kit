# 01-prompt-board
Bài nhập môn: dùng AI hỗ trợ sửa hai hành vi trên bảng việc có sẵn.

## Chạy bài
1. Cài Node.js >=22. Bộ này đã được kiểm thử bằng Node 24.15.0 trên Windows.
2. Mở terminal ngay trong thư mục chứa package.json.
3. Chạy `npm test`. Nhánh starter có test đỏ có chủ đích, chi tiết trong LAB.md.
4. Chạy `npm start` nếu bài có giao diện/server. Nhấn Ctrl+C để dừng.

Không có dependency bên ngoài, không cần npm install, tài khoản AI, API key hay mạng để chạy code/test.
Nếu dùng AI hỗ trợ sửa bài, cần công cụ/tài khoản AI do lớp chuẩn bị riêng. Có thể làm tay khi AI lỗi.
Đọc LAB.md để làm bài, docs/spec.md để biết hành vi đúng.

## Git và giới hạn
Gói học viên không chứa đáp án và lịch sử Git. Tạo repo riêng bằng `git init -b main` nếu cần.
Repo giảng viên có các nhánh main, starter, solution và tag bai-tap, dap-an.
Source được tạo riêng cho bộ hỗ trợ, không phải bản hoàn chỉnh của dự án React/TypeScript trong giáo trình gốc.
